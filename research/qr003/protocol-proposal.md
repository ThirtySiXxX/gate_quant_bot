## 2. 必须遵守的实际执行语义

依据 `strategy_signals.signal_at`、`strategy_execution.decide_execution` /
`build_order_plan`、`ExecutionTiming`、`EntrySizingBook` 和 `run_portfolio_backtest`：

- 在小时开盘 t 决策，信号只读已结束的小时/4h/日线，协方差也按已结束的 4h 对齐。
  模型输入最多使用 t 之前结束的行情；本根 close/high/low 和未来资金费不得进入特征。
  相对信号棒 t−3600，成交使用下一根开盘 t，加原有不利滑点。这里仍有零数据延迟假设。
- 方向来自原 allocation/forecast 与 invert_direction 设置；过滤器只允许或跳过
  新开仓，不改方向，不关闭已有仓，不修改 ATR、弱信号、反向退出或仓位缓冲。
- 当前 ETH fixture 的有效规则包括 trail_atr=3、trend agreement、反向先平仓等。
  `rearm_after_loss`、`adverse_exit` 和 daily-loss gate 未开启，保持未开启。
  不能把 RiskConfig 中存在的 time_stop_bars 等字段假定为本执行路径实际生效的退出。
- 固定保证金票据由当时权益、可用额度、档位、价格和整数张数决定；ETH 请求 200x，
  5% 权益保证金对应约 10x 初始账户名义敞口。固定票据不加仓，但支持原政策减仓。

  空仓时过滤入场，退出继续走原路径。普通回放没有事件级日志/暂停恢复的公开 API。

## 3. 可操作的事件与标签定义（M1 验证，不先假定可批量训练）

**候选事件**以 `(ETH_USDT, decision_at=t, trajectory_id, state_id)` 标识。
先记录所有有有效 signal/covariance 且当时空仓的决策点，再区分：

1. 通过原非 ML 时机、方向、rebalance 和 allow_increase 条件，model_target 非零的
   pre-ML 入场提议；侧向取原提议，不能由将来的涨跌选择。
2. 原 build_order_plan 在该执行时点预算/张数/档位校验后是否真的可开仓。
   额度拒绝、无可执行价格或最小张数不足要单列，不伪造为零收益负样本。
3. 在该条实际模拟轨迹上确实开仓的事件，其完整持仓生命周期记录为一个位置事件。
   不把同一次持仓的每小时记录、减仓腿或多条分支重复当作独立入场样本。

候选资格不能以“后来赚钱/最终被执行”为筛选条件。当前价格只供原票据和成交逻辑，
不把下一棒成交结果回填为前一棒的预测特征。M1 记录原 21 个因果特征的可用性，
以及当时方向、forecast、timing quality 和可观察的账户/时机状态；本轮不生成这些记录。

对状态 S_t 上允许执行的入场，**局部退出标签候选**定义为：按原政策连续模拟，
跟踪同一 position_id 到首次自然完全平仓 τ，包括所有减仓腿；
`z = 该位置全部已实现净 PnL / 初始实际成交名义金额`（无量纲），并可描述性记录
`y = 1[z>0]`。零净收益不标为正类。不把 z 称为保证金收益率、账户收益或相对跳过的优势。

净 PnL 使用原滑点成交价、各腿手续费和资金费分摊。滑点已在成交价中，不二次扣除。
原 funding 是按 `elapsed / funding_interval` 乘以当时 as-of 已知历史费率计提，
正值为支出；不是精确复刻交易所逐次结算。本标签保持并披露此近似，不能悄悄改口径。
正常费用为每侧 taker .0005、滑点 2 bps；double-cost 后续仅翻倍手续费/滑点，资金费不翻倍。

自然退出标签的 `label_end` 是最后一笔结算该位置的实际模拟成交时点，并记录所有
标签所需信息的最大可用时间。特征只在入场时截断，标签允许使用之后已实现的路径。
数据结束、缺口/缺失退出输入或无法观察自然退出时标为 censored，z/y 为空，保留原因
及 observation_end；不能当亏损或收益零，也不为得到标签新增固定时间止损。
原回放会以最后一根 close 强平，并用该棒的开盘时间记日志；这种终止记录单列为删失，
不能把其记录时间误作 close 已可见时间。末棒 close 最早在 open+3600 才可用。

## 4. 路径依赖：M1 的核心，而不是事后免责声明

跳过一次入场会改变权益、占用保证金、票据比率、last_fill/entry/best_close 等状态，
从而改变之后的资格和退出路径。亏损重入/日亏损开关当前虽关闭，也不得重置其状态
来构造一个“看起来空仓”的伪样本。不同政策下 S_t 不一定相同。

因此：只给已成交的 32 笔贴标签，会遗漏“跳过后在原来持仓期间出现”的新机会；
把每小时都强制从空仓、固定本金重启，又改变了原策略问题。两者都不能声称得到完整
可训练的入场选择数据。z 只是给定状态与续行政策的局部持仓结果，独立事件 z 求和
不是组合收益；正 z 也不等于比跳过并等待下一机会更好。

**有限诊断替代**：不做全量分叉标签生成器。M1 最多四条完整 ETH 轨迹：

- 一条原策略、ML 关闭、全允许的恒等重现。
- 三条从同一起始账户/日期重放的诊断，各只在一个固定时点拒绝一次新入场：
  1785607200（08-01 18:00）、1788040800（08-29 22:00）、1790618400（09-28 18:00），均 UTC。
  它们是既有基线每个旧时间段的首次入场，按时间选取，不按盈亏挑选。
  下一时点恢复原入场条件，绝不增加等待周期；不能复用基线之后的账户/持仓状态。

记录这四条轨迹中所有上述候选及阻挡原因、自然退出/删失，以及跳过后的首次资格
分歧。分支中的重复市场区间、相同起源事件必须关联去重。分支仅用于诊断状态和
样本选择偏差，不能因新增分支把样本量乘四，也不能挑收益最高的一条成为策略。
它们仍不是所有未来过滤政策的状态覆盖；若只获得已执行交易表，M1 不得宣称标签问题已解决。

优先在研究侧显式 observer/wrapper 调用原回放及共享执行函数，仅在这三个新开仓点
实施可审计的 skip-once。不得复制回测循环、制作另一套成交器或改生产函数。
如果观察/过滤边界无法在这些条件下忠实实现，交付具体阻塞及最小接口请求，回到用户
决策；不能用固定持仓时长或独立单位头寸回测冒充“原退出对齐标签”。

Phase A 必须回答四个未决问题，而不是预先保证可以构造训练集：

1. 能否在不多调用/改变策略状态的情况下，记录完整的 pre-ML 资格及拒绝原因？
2. 跳过后的再次提议、原持仓期间新出现的机会，如何定义事件并避免重复计数？
3. 原退出路径的成本、部分退出及删失时点能否一致核对；哪些状态缺少标签？
4. 去掉重复分支和时间依赖后，剩余证据是否足以达到用户预先接受的研究精度？

## 6. 后续模型/组合评估仅作条件性概要

Phase A 完成后，D2 才能决定是否训练。现在没有充分理由直接训练。
若批准，预算上限建议为一个预先固定的低维线性退出目标模型、一个同模型/同特征的
四小时目标对照，以及各自训练均值先验和 ML 关闭的原策略对照；不增加模型家族或
超参数网格。具体输入、参数、经济最小差异和可接受区间宽度须在训练前锁定。

两个目标用同一事件总体和公共时间切分，训练取标签均成熟的交集；标准化只拟合训练段。
变量标签要求 `max(label_end_exit, label_end_4h) + 86400 < 下一阶段起点`。
沿用旧区间只能作回顾性诊断：第一段是种子训练期，后两段才可能评估；缺少成熟标签、
无目标变化或资料不足就停止该折，不用重采样补充。未成熟事件单列删失；既有仓位不因
切分点强平。阈值优先固定为预测净收益大于零；如需调整，只允许事先批准的内层过去
验证段，使用相同 purge/embargo，不能参考外层收益。它不是已批准的风险限额。

不同目标的原始 log-loss/MAE/RMSE 不直接比较；各自与同目标先验比较，跨目标的最终
判断用共同日期、完整账户续行、原退出/仓位规则下的正常/双倍费用政策结果。
依赖以共同市场时间与事件簇处理，分支不能当独立样本。区间太宽、单事件主导、零交易
或负结果都如实保留；不把局部标签收益相加冒充组合收益。未获新决策，不执行这些比较。
新净收益分数不具有现有 short/neutral/long 概率含义，不塞入旧 JSON 或更改共享契约。
